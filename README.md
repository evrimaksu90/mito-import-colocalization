# mito-import-colocalization & SLC25A4-TOM20 colocalization
Analysis scripts for the manuscript "<A Shared Mitochondrial Protein Import Defect in Genetically Distinct Muscular Dystrophies>".

- MitoGFP_TOM20_Manders_M1/ – MitoGFP–TOM20 colocalization (Manders' M1)
- SLC25A4_TOM20_Manders_M1/ – SLC25A4–TOM20 colocalization (Manders' M1)

See the README in each folder for usage.
